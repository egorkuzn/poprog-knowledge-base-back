## 1 Общие сведения

### 1.1 Назначение документа
Настоящий документ содержит описание программы POPROG Knowledge Base Back и оформлен в соответствии с требованиями ГОСТ 19.402-78 и ГОСТ 19.105-78.

### 1.2 Наименование и обозначение программы
- Наименование: POPROG Knowledge Base Back
- Условное обозначение: `poprog-knowledge-base-back`

### 1.3 Основание для разработки
Внутренний проект POPROG по созданию единой базы знаний для публикаций, студенческих работ и материалов проектного меню.

### 1.4 Область применения
Программа используется как серверная часть веб-платформы POPROG и предоставляет API для пользовательского интерфейса, а также функции загрузки и поиска данных.

## 2 Назначение программы

Программа предназначена для:
- ведения каталога публикаций;
- ведения каталога студенческих работ;
- хранения и выдачи файловых ресурсов;
- полнотекстового поиска по метаданным и содержимому PDF;
- обслуживания проектного меню в клиентском приложении.

## 3 Функциональные характеристики

Программа обеспечивает:
- получение публичных списков публикаций и работ;
- группировку публикаций по годам;
- группировку студенческих работ по типу проекта;
- CRUD-операции для административного управления сущностями;
- загрузку PDF-документов и выдачу публичных ссылок;
- загрузку ресурсов проектного меню;
- интеграцию с Elasticsearch для полнотекстового поиска.

Примечание: административные операции в OpenAPI помечены префиксом `[ADMIN]` в `summary`.

## 4 Состав и структура программы

Программа реализована по гексагональному подходу и содержит слои:
- `adapters/inbound` — REST-контроллеры;
- `adapters/outbound` — интеграции с БД, Elasticsearch, файловым хранилищем;
- `application` — сценарии и прикладная логика;
- `domain` — доменные модели и правила;
- `config` — конфигурация приложения.

## 5 Описание функций

### 5.1 Функции управления публикациями
- создание, обновление, удаление публикаций;
- загрузка публикации с PDF-документом;
- выдача сгруппированного списка публикаций.

### 5.2 Функции управления студенческими работами
- создание, обновление, удаление студенческих работ;
- загрузка студенческой работы с PDF-документом;
- выдача сгруппированного списка работ.

### 5.3 Функции управления меню проектов
- создание, обновление, удаление секций меню;
- создание, обновление, удаление карточек и промо-блоков;
- загрузка ресурсных файлов для меню проектов.

### 5.4 Функции поиска
- полнотекстовый поиск по публикациям и работам;
- учет текста загруженных PDF-файлов.

## 6 Входные и выходные данные

### 6.1 Входные данные
- JSON-запросы к REST API;
- `multipart/form-data` для загрузки файлов;
- строковые параметры поиска.

### 6.2 Выходные данные
- JSON-ответы с данными доменных сущностей;
- коды HTTP-статусов результата обработки;
- публичные URL загруженных ресурсов.

## 7 Обработка ошибок и диагностические сообщения

Программа использует стандартные коды HTTP:
- `200`, `201`, `204` — успешное выполнение;
- `400` — ошибка валидации или некорректные входные данные;
- `404` — запрашиваемый объект не найден;
- `409` — конфликт при создании/обновлении данных;
- `413` — превышен допустимый размер файла;
- `503` — временная недоступность зависимого сервиса.

## 8 Условия эксплуатации

- среда выполнения Java 21;
- доступ к PostgreSQL;
- доступ к Elasticsearch;
- доступ к файловому хранилищу;
- работоспособная сеть между сервисами системы.

## 9 Требования к программным и техническим средствам

- JVM: Java 21;
- СУБД: PostgreSQL 18;
- Поисковый движок: Elasticsearch 9.x;
- Контейнерная инфраструктура (локально): Docker и Docker Compose.

## 10 Ограничения

- поддерживаемый формат документов для upload публикаций и студенческих работ: PDF;
- максимальный размер загружаемых файлов определяется конфигурацией backend;
- авторизация и разграничение ролей в текущей версии не реализованы на уровне enforcement;
- признак административности операций фиксируется через OpenAPI-метки `[ADMIN]`.
