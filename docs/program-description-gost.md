# Описание программы (ГОСТ 19.402-78, ГОСТ 19.105-78)

## Титульный лист

**Организация:** POPROG

**Обозначение документа:** ОП.19.402-78

**Вид документа:** Описание программы

**Разработчик:** Команда POPROG (backend)

**Утверждаю:** Руководитель проекта POPROG

**Город:** Новосибирск

**Год:** 2026

---

## 1. Общие сведения

### 1.1 Назначение документа
Данный документ содержит описание программы в соответствии с ГОСТ 19.402-78 и общими требованиями к программной документации по ГОСТ 19.105-78.

### 1.2 Наименование программы
**POPROG Knowledge Base Back** — backend-сервис для хранения и поиска публикаций и студенческих работ.

### 1.3 Основание для разработки
Внутренний проект POPROG по созданию базы знаний и инфраструктуры поиска.

### 1.4 Область применения
Система используется как серверная часть веб‑платформы POPROG, предоставляет API и поиск для фронтенда и внутренних сервисов.

## 2. Назначение программы

Программа предназначена для:
- хранения сведений о публикациях и студенческих работах;
- предоставления API для доступа к данным;
- полнотекстового поиска, включая текст PDF‑документов;
- управления загрузкой документов и формированием публичных ссылок.

## 3. Функциональные характеристики

Программа обеспечивает:
- CRUD‑операции для публикаций и студенческих работ;
- выдачу публикаций, сгруппированных по годам;
- выдачу студенческих работ, сгруппированных по типу проекта;
- полнотекстовый поиск по метаданным и текстам PDF;
- загрузку PDF‑документов и хранение ссылок;
- автоматическое применение миграций базы данных.

## 4. Логическая структура программы

Программа построена по гексагональной архитектуре:
- **Adapters (inbound/outbound)** — REST API, интеграции с Elasticsearch и PostgreSQL;
- **Application** — бизнес‑логика и сценарии;
- **Domain** — предметная область;
- **Config** — конфигурация приложения.

## 5. Описание функций программы

### 5.1 Управление публикациями
- Создание, обновление, удаление публикаций
- Группировка публикаций по году
- Загрузка PDF‑документа и сохранение ссылки

### 5.2 Управление студенческими работами
- Создание, обновление, удаление работ
- Группировка по типу проекта
- Загрузка PDF‑документа и сохранение ссылки

### 5.3 Поиск
- Полнотекстовый поиск по метаданным и тексту PDF
- Поддержка частичных совпадений при вводе от 3 символов
- Асинхронная индексация PDF после загрузки

## 6. Входные и выходные данные

### 6.1 Входные данные
- JSON‑запросы для CRUD API
- Multipart/form‑data для загрузки PDF
- Строка запроса для поиска

### 6.2 Выходные данные
- JSON‑ответы с данными о публикациях и работах
- Результаты поиска
- Ссылки на загруженные файлы

## 7. Сообщения об ошибках

- `400` — неверные параметры запроса или некорректный файл
- `404` — объект не найден
- `413` — превышение допустимого размера загрузки
- `503` — временная недоступность сервиса (например, нет соединения с БД)

## 8. Условия эксплуатации

- Наличие PostgreSQL и Elasticsearch
- Наличие локального файлового хранилища
- Среда исполнения: Java 21
- Возможны задержки появления результатов поиска после загрузки PDF

## 9. Требования к программным и техническим средствам

- Java 21
- PostgreSQL 18
- Elasticsearch 9.x
- Docker (для локального запуска)

## 10. Ограничения

- Поддерживаемый формат документов: PDF
- Максимальный размер загружаемого файла: 25 MB
- Операции вставки/модификации/удаления и загрузки документов относятся к роли администратора (помечены `[ADMIN]` в OpenAPI)
- Авторизация и роли пользователей в текущей версии не реализованы (ограничение фиксируется на уровне документации)
- Удаление записи не удаляет файл автоматически из хранилища
